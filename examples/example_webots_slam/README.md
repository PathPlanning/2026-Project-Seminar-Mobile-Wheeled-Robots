# SLAM робота в Webots

Пример запускает TurtleBot3 Burger в сцене с тремя коробками из `example_webots_localization`. Робот движется по окружности, а `slam_toolbox` строит карту по сканам LiDAR и колёсной одометрии. Супервизор публикует истинную позу робота.

Соберите пакет в подготовленном окружении курса и подключите окружение:

```bash
colcon build --packages-select example_webots_slam
source install/setup.bash
ros2 launch example_webots_slam spawn_robot.launch.py
```

Чтобы запустить пример без RViz:

```bash
ros2 launch example_webots_slam spawn_robot.launch.py use_rviz:=false
```

При запуске используется стандартный `online_async_launch.py` пакета `slam_toolbox` и его стандартные параметры построения карты. Дополнительно передаётся `use_sim_time:=true`. В частности, стандартное разрешение карты SLAM может отличаться от разрешения эталонной карты.

Эталонная карта сцены публикуется узлом `reference_map_server` в топик `/reference_map`; построенная SLAM карта публикуется в `/map`. Эталон не передаётся в `slam_toolbox`. В RViz карта SLAM включена по умолчанию, а эталонную можно включить в панели Displays. Для просмотра одной из карт удобно выключить другую.

Система `world` совпадает с глобальной системой координат сцены. Эталонная карта и трансформ истинной позы `world → base_link_gt` задаются в этой системе. Карта SLAM использует систему `map`, а колёсная одометрия — `odom`:

```text
world
├── base_link_gt
└── map
    └── odom
        └── base_link
```

Статический трансформ `world → map` соответствует начальной позе робота в сцене: `x = 1 м`, `y = 0 м`, `yaw = π/2`. Он позволяет сопоставить эталон и карту SLAM при начальной системе одометрии в позе робота. `slam_toolbox` публикует динамический `map → odom`, поэтому после исправлений SLAM оценка робота может отличаться от истинной позы. Если изменить начальную позу робота или способ инициализации одометрии, необходимо соответственно изменить этот статический трансформ.

Для проверки топиков можно использовать:

```bash
ros2 topic info /map -v
ros2 topic info /reference_map -v
ros2 run tf2_ros tf2_echo world base_link_gt
```
