# Установка Ubuntu 24.04 ARM Desktop в UTM на Mac

Инструкция по установке Ubuntu 24.04 для **Mac с Apple Silicon (M1 и новее)**. Установка на Mac с процессорами Intel не проверялась, однако должна происходить аналогично, при выборе образа под архитектуру x64. 

## 1. Подготовьте Mac

Проверьте процессор в меню Apple → «Об этом Mac». Для этой инструкции нужен чип Apple серии M. 

Параметры виртуальной машины в зависимости от конфигурации:

| Параметр | Значение |
| --- | --- |
| Оперативная память виртуалки | 8 ГБ при 16 ГБ и более на Mac; 4 ГБ при 8 ГБ на Mac (можно ставить больше, если в вашей конфигурации доступно больше ОЗУ) |
| Процессоры виртуалки | 4 ядра; |
| Виртуальный диск | 64 ГБ или больше |
| Свободное место на Mac | Желательно не менее 70 ГБ с запасом под ISO и рост диска |

Не выделяйте виртуалке всю оперативную память, часть нужна macOS.

## 2. Установите UTM и ISO Ubuntu

1. Скачайте UTM для macOS на [официальном сайте UTM](https://mac.getutm.app/) и установите его. Можно также установить версию из Mac App Store.
2. Скачайте ISO образ Ubuntu 24.04 Desktop для ARM с [официального сайта Ubuntu](https://cdimage.ubuntu.com/ubuntu/releases/noble/release/). Нужен именно установочный iso образ для ARM. Образы `amd64`, Raspberry Pi (`raspi.img.xz`) и `live-server` для описанного способа не подходят. Флешка не требуется: ISO подключается непосредственно к виртуалке.
3. В UTM нажмите **+ → Create a New Virtual Machine**.
4. Выберите **Virtualize → Linux**.
5. Задайте память и количество ядер из таблицы выше. **Включите аппаратное ускорение OpenGL.**
6. На следующем шаге отключите флажок **Use Apple Virtualization**
7. Выберите загрузку с ISO (**Boot from  ISO Image**) и через **Browse** укажите скачанный образ.
8. Укажите размер диска **64 GB**.
9. Экран общей папки можно пропустить.
10. Назовите машину, например **Ubuntu 24.04 ARM64**, и сохраните её. Пока не запускайте ее.

## 3. Проверьте настройки 3D 

После предварительной настройки ВМ в UTM откройте ее настройки (**ПКМ по пункту меню с нужной ВМ → Edit**) и проверьте ее параметры.

| Раздел | Что проверить |
| --- | --- |
| System | Архитектура **ARM64 / aarch64**, стандартная для ARM система **virt** |
| QEMU | Аппаратная виртуализация **Use Hypervisor** включена, если параметр доступен; UEFI Boot включён |
| Display → Emulated Display Card | **virtio-gpu-gl-pci**, с пометкой **GPU Supported** |
| Display | Индикатор поддержки GPU/OpenGL включён |
| Network | **Shared Network**, чтобы Ubuntu получила интернет через Mac |
| Drives | Созданный виртуальный диск и подключённый установочный ISO |

UTM рекомендует `virtio-gpu-gl-pci` для Linux. В некоторых версиях также доступен `virtio-ramfb-gl` с пометкой **GPU Supported**. Обычные варианты без `-gl` не обеспечивают описанное VirGL-ускорение.  Сохраните настройки. Ускорение OpenGL через VirGL в UTM считается экспериментальным, совместимость зависит от приложения. 

## 6. Установите Ubuntu

1. Нажмите **Run / ▶**.
2. В загрузочном меню выберите **Try or Install Ubuntu**.
3. Дождитесь графического установщика. Если открылся рабочий стол, запустите **Install Ubuntu**.
4. Выберите язык, параметры доступности при необходимости и раскладку клавиатуры.
5. Используйте предложенное проводное подключение к сети: виртуалка получает его через UTM.
6. Выберите **Install Ubuntu → Interactive installation**.
7. Выберите стандартный набор приложений (**Default selection**). Расширенный набор для установки рабочего стола не обязателен.
8. Установку стороннего ПО можно пропустить: VirtIO/VirGL использует драйверы Linux и Mesa из Ubuntu.
9. На экране диска выберите **Erase disk and install Ubuntu**. В этой конфигурации речь о новом виртуальном диске на 64 ГБ. Проверьте его размер перед подтверждением.
10. Создайте пользователя и пароль, выберите часовой пояс.
11. Проверьте сводку и запустите установку.
12. Дождитесь завершения и нажмите **Restart Now**.

Последовательность экранов может немного меняться. [Официальная инструкция Ubuntu Desktop 24.04](https://ubuntu.com/desktop/docs/en/24.04/tutorial/install-ubuntu-desktop/).

Когда Ubuntu попросит извлечь установочный носитель, в окне UTM откройте меню CD/DVD и выберите **Eject / Clear** для ISO, затем нажмите Enter внутри виртуалки. Если перезапуск завис, после завершения установки остановите виртуалку, отключите ISO в настройках съёмного привода и запустите её снова. 

## 7. Установите обновления и гостевые инструменты

Войдите в установленную Ubuntu. Откройте **Terminal** через список приложений или сочетанием **Ctrl + Alt + T**. Все следующие команды выполняются **в Ubuntu**, а не в терминале macOS.

Обновите систему:

```bash
sudo apt update
sudo apt upgrade -y
```

Установите инструменты интеграции с UTM и утилиту проверки OpenGL:

```bash
sudo apt install -y spice-vdagent qemu-guest-agent mesa-utils
sudo reboot
```

При вводе пароля после `sudo` символы в терминале не отображаются — это нормально.

`spice-vdagent` обеспечивает интеграцию буфера обмена и изменение разрешения окна; `qemu-guest-agent` — взаимодействие гостевой системы с виртуализацией QEMU.

## 8. Проверьте завершение установки

После перезагрузки откройте терминал в графическом окне Ubuntu и выполните:

```bash
lsb_release -d
uname -m
glxinfo -B
```

Ожидаемый результат:

- Версия системы — **Ubuntu 24.04.x LTS**.
- Архитектура — **aarch64**.
- В строке **OpenGL renderer string** присутствует **virgl**, если выводится поле **Accelerated**, ожидается **yes**.

`virgl` означает, что проверяемый OpenGL-контекст использует виртуальный 3D-драйвер. Значение `llvmpipe` или `softpipe` означает программный рендеринг на CPU. Одна строка `direct rendering: Yes` не подтверждает GPU-ускорение.

### Если возникла проблема

- **Снова появляется установщик:** выключите виртуалку и отключите ISO в съёмном CD/DVD-приводе.
- **UEFI Shell вместо установки:** проверьте, что подключён ARM64 ISO, затем перезапустите машину.
- **Чёрный экран при установке с 3D:** выключите виртуалку, временно выберите `virtio-ramfb`, установите Ubuntu и обновления, затем выключите её и верните `virtio-gpu-gl-pci`. После запуска повторите `glxinfo -B`; временная установка без 3D не считается проверкой ускорения.
- **После установки выводится `llvmpipe`:** полностью выключите Ubuntu и перепроверьте QEMU backend и видеоустройство с пометкой **GPU Supported**. Затем загрузитесь и выполните проверку в терминале рабочего стола UTM.

Установка завершена, когда Ubuntu запускается с виртуального диска без ISO, работает интернет и проверка OpenGL показывает VirGL.
